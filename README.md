# ClaimFund Login UI

React + Vite login page with responsive modern corporate/insurance UI.

## Run

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
```

The login submit currently logs the form data to the browser console.
Replace `submit()` in `src/components/LoginForm.jsx` with your real authentication API.
